**Smart Image Tool** is a lightweight, fast, and easy-to-use Android application designed to handle daily image tasks like resizing, compression, format conversion, and basic enhancements directly on your device.

## ✨ Key Features

* **🗜️ Smart Compression:** Reduce image file size (KB/MB) without losing visible quality.
* **📐 Custom Resizing:** Resize images by pixels, percentage, or preset aspect ratios.
* **🔄 Format Converter:** Convert seamlessly between `JPG`, `PNG`, and `WEBP`.
* **🔒 100% Offline & Private:** All image processing happens locally on your phone; no images are uploaded to any server.
